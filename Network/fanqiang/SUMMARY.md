# 一句话说明

这是一个把多平台代理教程、客户端线索、协议资料、应用源码和历史归档放在一起的资料集合，适合用来建立问题地图，不适合直接当作当前安装手册或可信软件下载源。

# 它解决什么问题

**Fact:** 仓库按 Windows、Android、iOS、macOS、Linux、路由器和游戏设备组织代理相关内容，并覆盖 V2Ray、Shadowsocks、Clash、Tor、系统代理、局域网共享和路由分流。

**Analysis:** 它最有价值的不是某个具体下载链接，而是展示了网络代理问题会同时涉及协议核心、客户端、订阅格式、系统代理、DNS/路由、平台权限和网关设备。

# 核心功能

- 跨平台客户端和配置教程索引。
- V2Ray/Shadowsocks 等协议及服务端的历史资料。
- 路由器、旁路由和局域网共享场景。
- 多个应用或打包工具的源码、资产及下载入口。
- 显式 `deprecated/` 历史归档。

# 核心技术

代理核心与客户端、系统代理、VPN/TUN、PAC/规则路由、订阅配置、Android/Kotlin 应用、OpenWrt/路由器和浏览器打包工具。仓库不是一个统一架构的软件产品。

# 主要目录

平台教程优先看 `windows/`、`android/`、`ios/`、`macos/`、`linux/`、`router/`；协议和服务器词汇看 `v2ss/`；历史内容看 `deprecated/`；不要为了研究概念进入体量最大的 `fqnews2/` 应用实现。

# 主要模块

这里的“模块”是内容域，不是稳定 API：平台配置、客户端选择、协议核心、订阅和节点、路由与网关、浏览器/程序打包、Android 应用，以及历史归档。

# 工作方式

用户从平台或场景进入教程，再选择客户端和协议。部分页面进一步指向外部服务、下载包或上游项目。内容时效并不统一，仓库最近更新不能证明每一篇教程都仍然有效。

# 适合什么场景

- 盘点代理系统需要处理的能力和平台差异。
- 查找旧工具名称、迁移线索和历史背景。
- 研究客户端、核心、系统代理和路由层之间的职责划分。
- 为后续官方文档检索生成关键词。

# 不适合什么场景

- 直接运行其中的可执行文件、APK、脚本或自动安装器。
- 把仓库内推荐、外部服务或免费节点视为已验证的当前建议。
- 依据旧教程设计安全敏感的生产网络。
- 整体复制或重新发布该仓库。

# 最值得看的东西

跨平台目录、路由器/旁路由场景、V2Ray/Shadowsocks/Clash/Tor 的概念关系，以及 `deprecated/` 对历史方案的显式隔离思路。

# 可以暂时不看的东西

`fqnews/`、`fqnews2/` 的完整应用实现，推广和注册链接，免费节点页面，浏览器一键包，二进制资产，以及 `deprecated/` 中的 GoAgent/PAC 细节。

# 对本资料库的价值

它提供的是“网络代理已有轮子地图”和过时案例库。它提醒后续 AI：不要从零发明协议和客户端，但必须回到当前官方上游重新验证版本、许可证、来源和安全性。

# 30 秒快速判断

需要理解代理能力、平台差异或历史方案时值得查；需要安装、下载或给出当前安全建议时，只把它当线索，必须联网核对官方上游，绝不直接执行仓库内程序。
