# License Recommendation

## Current State

No final license has been selected. Until the owner chooses and adds a license, the original knowledge-base content is not yet offered under a standard open-source or open-content license.

## Recommended Options

### Option A: CC BY 4.0 for knowledge content

Permits reuse and adaptation with attribution. This is the simplest fit for original Markdown analysis, indexes, diagrams, and guides when broad reuse is desired.

### Option B: CC BY-SA 4.0 for knowledge content

Adds a share-alike requirement. It protects continued openness but can make reuse in mixed-license documentation less convenient.

### Optional code license

If validation or generation scripts are added later, license those files separately under MIT or Apache-2.0. Apache-2.0 adds an explicit patent grant; MIT is shorter and simpler.

## Recommendation

Use `CC BY 4.0` for original knowledge content and `Apache-2.0` for future substantive scripts, with a clear file-level boundary. This is a recommendation only, not the final selection.

## Third-party Material

The knowledge-base license cannot relicense upstream source code, quoted material, trademarks, or other third-party content. `ATTRIBUTION.md` and every `META.md` must preserve provenance and upstream license facts.
