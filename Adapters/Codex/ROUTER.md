# Codex KB Router

For non-trivial reusable capabilities, architecture or system design, framework integration, technology selection, or uncertain implementation paths, first run:

`python <KB_ROOT>/tools/kb.py search "<capability>"`

Skip the KB for typos, formatting, simple renames, localized bugs, explanations, and small changes whose implementation is already specified. Retrieve progressively: `search` -> `show`/`reuse` -> `architecture` -> `source/` only when justified. Never preload the knowledge base or reread the same material without a changed need.
